# Rime 嘸蝦米

## 簡介

嘸蝦米，只需要記得 26 個英文字母加一個空白鍵就可以打中文字的輸入法

改變輸入法模式
- 注音模式: 輸入「`';`」進注音模式
- 讀音反查: 輸入「`;;`」進入讀音反查模式

快捷鍵
- `Ctrl + '` : 切換反查
- `Ctrl + .` : 切換簡繁
- `Ctrl + /` : 切換擴充字集

## 安裝

[東風破](https://github.com/rime/plum) 安裝
```
bash rime-install nyorc/rime-liur
```
